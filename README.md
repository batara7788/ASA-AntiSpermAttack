# ASA: AntiSpermAttack

Бесплатный антивирус для Windows 10 и 11. Без рекламы, без подписок, без телеметрии.

Проверяет файлы движком [ClamAV](https://www.clamav.net/): он бесплатный, с открытым кодом, а вирусные базы обновляются каждый день.

## Что умеет

| Модуль | Что делает |
|---|---|
| Защита в реальном времени | Проверяет каждый новый или изменённый файл в Загрузках, на Рабочем столе, в Документах, временных папках и автозагрузке. Заражённый файл сразу уходит в карантин |
| Проверка процессов | Проверяет каждую запускаемую программу. Если она заражена, процесс убивается, а файл уходит в карантин |
| Проверка флешек | Флешка проверяется целиком сразу после подключения |
| Слежка за автозагрузкой | Предупреждает о каждой программе, которая прописалась в автозапуск Windows. Заражённую убирает сама |
| Защита от шифровальщиков | Раскладывает файлы-ловушки и следит за массовыми изменениями документов. Подозрительный процесс замораживается, а решение принимаете вы |
| Веб-щит | Блокирует сайты, которые раздают вирусы (база URLhaus), через системный файл hosts. Работает во всех браузерах |
| Карантин | Заражённые файлы хранятся зашифрованными и не могут запуститься. Файл можно восстановить или удалить |
| Умная проверка | Собирает программы, скрипты, ярлыки и файлы-притворщики из мест, где прячутся вирусы, оценивает каждый по признакам подозрительности (двойное расширение, нет подписи, упаковщик, скрытый атрибут, свежий файл и другие) и проверяет от самого опасного к безопасному. Самые подозрительные дополнительно проверяет Защитник Windows |
| Аудит системы | Проверяет 10 мест, где вирусы прячут автозапуск и ломают защиту: Защитник и его исключения, UAC, брандмауэр, перехват запуска программ, hosts, прокси, запланированные задачи, службы, ярлыки, подписки WMI, расширения браузеров. Найденное можно исправить одной кнопкой или пометить как доверенное |
| Ручная проверка | Быстрая, полная, папка, файл, запущенные процессы |
| Меню правой кнопки | «Проверить с помощью ASA» на любом файле, папке или диске |
| Проверка по расписанию | Полная проверка раз в неделю в выбранный день и час |
| Игровой режим | В играх и полноэкранном видео уведомления не показываются и плановая проверка откладывается |
| VirusTotal | Второе мнение от 70+ антивирусов. Сначала отправляется только отпечаток файла, сам файл уходит только по вашему решению |
| Очистка | Удаляет временные файлы и кэш браузеров (Chrome, Edge, Яндекс, Opera, Firefox) |
| Журнал и статистика | Всё, что сделал ASA, и график активности за 14 дней |

## Установка

1. Откройте вкладку **Actions** этого репозитория, выберите последний успешный запуск **build**.
2. Внизу страницы скачайте **ASA-Setup** (установщик) или **ASA-portable** (один exe).
3. Запустите. Windows SmartScreen предупредит, что издатель неизвестен (у программы нет платной цифровой подписи): «Подробнее» → «Выполнить в любом случае».
4. При первом запуске ASA сам скачает движок ClamAV (около 30 МБ) и вирусные базы (около 250 МБ). Это займёт несколько минут, статус виден на главном экране.

После установки ASA запускается вместе с Windows без запроса прав администратора: для этого он создаёт задачу в Планировщике заданий.

## Как проверить, что защита работает

Используйте тестовый «вирус» EICAR. Он безвреден, это просто строка текста, которую все антивирусы договорились считать вирусом.

1. Создайте в Загрузках текстовый файл `eicar.com`.
2. Вставьте в него эту строку и сохраните:
   ```
   X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*
   ```
3. Через секунду ASA покажет уведомление, а файл окажется в карантине.

Если у вас включён Защитник Windows, он может перехватить файл раньше ASA. Для теста временно отключите в Защитнике «Защиту в реальном времени».

## Чем ASA отличается от платных антивирусов

- **Нет драйвера ядра.** Платные антивирусы перехватывают файл до того, как его откроют. ASA замечает файл через долю секунды после появления. Для драйвера нужна подпись Microsoft, это платно.
- **ClamAV ловит меньше, чем коммерческие движки**, особенно совсем свежие угрозы. Поэтому **Защитник Windows лучше не выключать**: ASA спокойно работает рядом с ним как второй слой.
- **Защита от шифровальщиков эвристическая.** Она может сработать на легитимную массовую операцию, например переименование сотни фотографий. Поэтому ASA не убивает процесс сам, а замораживает его и спрашивает вас.

## Где что лежит

- Программа: `C:\Program Files\ASA`
- Данные (базы, карантин, журнал, настройки): `C:\ProgramData\ASA`
- Резервная копия hosts до первого изменения: `C:\Windows\System32\drivers\etc\hosts.asa-backup`

При удалении через «Установка и удаление программ» ASA убирает автозапуск, пункт меню и блок-лист из hosts. Карантин и настройки остаются в `C:\ProgramData\ASA`, их можно удалить вручную.

## Сборка из исходников

Нужен .NET 8 SDK.

```bash
dotnet test tests/ASA.Core.Tests
dotnet publish src/ASA.App/ASA.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Установщик собирается [Inno Setup](https://jrsoftware.org/isinfo.php) из `installer/ASA.iss`. GitHub Actions делает всё это автоматически при каждом пуше.

## Структура

```
src/ASA.Core/     логика без привязки к Windows: клиент ClamAV, карантин, веб-щит, детектор шифровальщиков, очистка, VirusTotal
src/ASA.App/      программа для Windows
  Services/       модули защиты
  Interface/      окно и страницы
tests/            тесты ядра
installer/        установщик
```
